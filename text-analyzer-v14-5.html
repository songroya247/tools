Burstiness (σ/μ)

Measures rhythm variation in sentence lengths. Human writers mix short punchy lines with long complex ones. AI tends toward uniformly medium sentences. >0.5 = human, <0.3 = AI-like. In v13, this is also updated in real-time by the GPT-2 Space with a true sliding-window burstiness score.

GPT-2 Real Perplexity (new in v13)

Replaces offline bigram perplexity as the primary PP metric. Calls the UltimateEdge HF Space for true sliding-window GPT-2 perplexity — a much stronger signal than bigram entropy. Falls back to offline bigram score if the Space is sleeping. Updates the Bigram PP card and injects a full verdict banner automatically on every analysis.

Datamuse Semantic Variance

Queries rel_trg associations for key nouns/verbs. Measures spread: AI text clusters associations tightly; human text ranges wider. Also checks noun–verb pair proximity for "flatness." Needs internet.

Transformers.js (Local)

Loads Xenova/all-MiniLM-L6-v2 in the browser — a 25MB sentence-transformer that converts words to vectors. Cosine similarity between key terms reveals semantic clustering. Offline after first download.

Compromise.js NLP

Tags every word by part of speech (noun, verb, adjective…). AI text tends toward syntactically regular, balanced POS distributions. Human writing shows more POS variability. 100% offline.

LLM Scoring (Groq / HuggingFace)

Groq runs Llama 3.1-8b-instant for real token log-probability perplexity and per-sentence AI likelihood scores. HuggingFace supports three modes: ModernBERT fine-tuned AI Detector (DAIGT V2), UE School AI Detector (3-model SzegedAI ensemble), or Masked-LM heuristic. Both need a free API key.

UltimateEdge Trained Model

Auto-runs on every analysis — no key required. Calls ultimateedge-ai-detector-v2-api.hf.space with your text and returns a binary classification (AI/Human), AI probability bar, and confidence score. Based on a fine-tuned ModernBERT classifier.

DeepSeek V4-Pro (new in v13)

A 1.6-trillion parameter Mixture-of-Experts model (49B activated) from DeepSeek, released April 2026 under MIT license. Supports 1M token context and three reasoning modes. Used here as a third LLM scoring provider alongside Groq and HuggingFace — provides per-sentence AI likelihood scores and an overall verdict via its OpenAI-compatible API at api.deepseek.com. Also triggers Arch-Router domain classification automatically when available. Needs DeepSeek API key.

Arch-Router 1.5B (new in v13)

A preference-aligned routing model from Katanemo (arxiv:2506.16655) based on Qwen2. Classifies text by domain (academic, legal, healthcare, programming, creative…) and action (summarization, argumentation, instruction…). Adds contextual signal to AI detection — domain/action mismatch can itself be an AI pattern indicator. Runs via HuggingFace Inference API. Triggers automatically when HF or Groq scoring is run with an HF key available. Needs HuggingFace key.
